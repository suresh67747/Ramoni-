# RAMONI Catalogue Manager

Independent product catalogue management software for RAMONI.

## Current foundation
- Professional admin dashboard inspired by the approved RAMONI layout
- Product master with add/edit/search/filter
- Product details panel
- Categories, brands, price list, catalogue builder, customers, enquiries, reports and settings workspaces
- Responsive desktop/mobile layout
- Local browser persistence for initial product records

## Production roadmap
1. Supabase database, authentication and image storage
2. Excel/CSV bulk import with image matching
3. Multi-image product gallery and full specifications
4. Catalogue ordering, templates and professional PDF generation
5. Customer/dealer enquiry workflow and notifications
6. Deployment and custom RAMONI domain

This repository is independent of RUHE India and is intended for the RAMONI project.
